Before you start

Get set up

Any room is fine. Bare leg or tight leggings. Loose pants or socks will be measured as part of the leg.

A standard-size card, flat on the floor. Any bank, gift or ID card. Lay it face down so no card number is in the photo. A light-colored back works best on dark floors.

A helper takes the photos. The person being measured stands still with weight on both feet.
